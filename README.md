## Ruang Lingkup

Desain mencakup seluruh user story pada soal:

- Registrasi dengan data diri, email, nomor telepon, foto KTP, dan swafoto
- Login dengan password + OTP atau biometric
- Informasi sisa hutang dan tagihan bulanan
- Pengajuan pinjaman maksimal Rp12.000.000 dengan tenor maksimal 12 bulan
- Keputusan pengajuan disetujui atau ditolak, dengan notifikasi email dan nomor telepon
- Pembatasan satu pinjaman aktif per user

Dokumen juga memuat analisis kebutuhan, business rules, spesifikasi validasi form, penanganan kegagalan verifikasi, keamanan dan kepatuhan (OJK, UU PDP), serta pertanyaan terbuka untuk stakeholder.
